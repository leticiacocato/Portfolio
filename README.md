# 📊 Portfolio

Welcome to my Data Analytics & Data Science Portfolio - a showcase of my projects, technical skills, and experience in data analysis, visualization, statistical modeling, and data-driven applications.

This repository includes projects developed using SQL, Python, R, Power BI, and statistical methods, covering areas such as business intelligence, data visualization, exploratory analysis, and interactive dashboards.

## Featured Projects

### 🛒 [Retail Sales Analysis — SQL & Power BI](https://github.com/leticiacocato/Portfolio/tree/main/Retail-Sales-Analysis)

A data analysis project focused on sales performance, profitability, customer behavior, product performance, regional results, and the impact of discounts using the **Sample Superstore** dataset.

The project combines **PostgreSQL/SQL** for exploratory and business analysis with **Power BI** for interactive data visualization and dashboard development.

#### Key Features:

- Exploratory and business analysis using SQL
- Analysis of sales, profit, margins, discounts, products, customers, and regions
- Interactive Power BI dashboard with KPI tracking and business insights

#### Tools & Technologies:

- **PostgreSQL**, **SQL**, **Power BI**, **DAX**
- **Data analysis**, **data visualization**, **business intelligence**

#### Key Insights:

- Technology generated the highest profit ($145.5K), while Furniture generated significantly less ($18.5K).
- Copiers generated the highest profit among subcategories ($55.6K), while Tables recorded the largest loss ($17.7K).
- Technology led in sales ($836.2K), profit ($145.5K), and profit margin (17.40%).
- High discount levels were associated with substantially lower profitability.

### 🗺️ [Geodata Dashboard: Singapore HDB Resale Prices](https://github.com/leticiacocato/Portfolio/tree/main/Geodata%20Dashboard)

An interactive dashboard built using **R Shiny** to visualize and explore **Singapore's HDB resale price trends** across time and space.

- Clean UI/UX optimized for usability.

#### Tools & Technologies:
- **R**, **Shiny**, **geoR**, **ggplot2**, **plotly**, **dplyr**, **tidyr**
- **Geospatial data**, **interactive dashboards**

#### Data:
- Singapore HDB Resale Price data from [Kaggle]([https://www.kaggle.com/](https://www.kaggle.com/datasets/talietzin/singapore-hdb-resale-prices-1990-to-2023))
