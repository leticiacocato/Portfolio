# Data

This project uses the **Sample - Superstore** dataset, obtained from Kaggle. Containing information about orders, customers, products, sales, profit, discounts, shipping and geographic information.

The dataset was used for exploratory analysis, business analysis and the development of the Power BI dashboard.

## Main Variables

The dataset includes information such as:

* Product and client ID
* Order and shipping dates
* Customer and segment
* Product category and sub-category
* Sales
* Quantity
* Discount
* Profit
* Shipping mode
* State and region

## Data Usage

The dataset is used exclusively for educational and portfolio purposes. It was processed and analyzed using **PostgreSQL, SQL and Power BI**.

The original raw dataset is included in this repository.
